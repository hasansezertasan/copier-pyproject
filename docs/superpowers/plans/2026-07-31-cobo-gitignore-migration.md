# Migrate `.gitignore` generation from gibo → cobo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `gibo`-generated `.gitignore` content with `cobo`-managed fenced regions plus a lockfile and a weekly non-blocking drift check, in both this template repo and every generated project.

**Architecture:** cobo writes a hash-fenced region (`# >>> cobo:begin >>>` … `# <<< cobo:end sha256=… <<<`) of verbatim `github/gitignore` boilerplate and records provenance in a `cobo.lock`. Content after the end fence is preserved by `cobo sync`/ignored by `cobo check`, so the two project-specific jinja conditionals move below the fence into the author section. This template repo gets a root `cobo.lock` (managing `template/.gitignore.jinja`); generated projects ship their own `template/cobo.lock` (managing `.gitignore`), `pipx:cobo` in mise, and a `gitignore-drift.yml` weekly cron.

**Tech Stack:** cobo 0.3.0 (Python CLI), copier + Jinja2, mise (`pipx:` backend), GitHub Actions, tox `style` env (taplo/editorconfig-checker/actionlint/zizmor).

## Global Constraints

- Boilerplate set is exactly: `macOS Windows Linux VisualStudioCode Python` (unchanged from gibo).
- cobo is **always-included** tooling — **no** `copier.yml` toggle (like mise/renovate).
- Fenced region must be **verbatim** cobo output — no jinja/no edits inside the fence (breaks the sha256).
- Pinned cobo version: `0.3.0` (Renovate tracks it thereafter, like `aqua:`/`npm:` tools).
- Drift check: weekly `schedule` + `workflow_dispatch` only — **not** `pull_request`, **not** in the `check` gate, **not** a prek/blocking hook (network-flaky; same posture as `docs-linkcheck`).
- Every new/edited workflow keeps the repo's zizmor posture: `permissions: {}` top-level, per-job least-privilege, `persist-credentials: false`, no untrusted `${{ }}` in `run:`.
- Regeneration is deterministic: `cobo update` then the exact `cobo` commands below reproduce byte-identical output. Current pin: `github/gitignore@57286c3887203259752b747db94e6c3ad10ec53d`, fence `sha256=7b55630309b1a589ad9064e76cd1db1052a7d0cedc0ce591a8329bc2a4b6802e`.
- Work happens on branch `feature/migrate-gitignore-to-cobo`.

taplo only lints `*.toml` (non-recursive), so it ignores `cobo.lock` (`.lock`). But
editorconfig-checker's `[*]` default is 4-space, while cobo writes 2-space subtable indent —
so `cobo.lock` needs its own stanza (same approach as `.all-contributorsrc`). Add to
`template/.editorconfig` after the `[.all-contributorsrc]` stanza:
```ini
# cobo.lock is a generated TOML lockfile (2-space subtable indent, like the
# other 2-space TOML above); the `.lock` extension is not covered by the
# TOML glob, so it gets its own stanza. taplo does not lint it (its glob is
# `*.toml`), leaving editorconfig-checker as the only indent authority here.
[cobo.lock]
indent_size = 2
```

### Task 4: Weekly drift-check workflow

**Files:**
- Create: `template/.github/workflows/gitignore-drift.yml` (static `.yml`, no jinja — cobo is unconditional)

**Interfaces:**
- Consumes: the `pipx:cobo` mise tool from Task 2 and `cobo.lock` from Task 1.

- [ ] **Step 1: Create the workflow**

Create `template/.github/workflows/gitignore-drift.yml` with exactly:
```yaml
---
name: Gitignore Drift Check
# Runs `cobo check` to detect when the checked-in .gitignore has drifted from
# the github/gitignore templates recorded in cobo.lock. `cobo update` hits the
# network and is inherently flaky, so this runs on a weekly schedule and on
# demand — never on pull_request, and it is not part of the `check` aggregation
# gate. A failure here is a maintenance signal (regenerate with cobo), not a
# merge blocker. Mirrors the docs-linkcheck.yml posture. See ADR-012.
on:
  workflow_dispatch:
  schedule:
    # Weekly, Monday 07:00 UTC.
    - cron: "0 7 * * 1"
permissions: {}
jobs:
  gitignore-drift:
    name: Check .gitignore drift
    runs-on: ubuntu-latest
    timeout-minutes: 10
    permissions:
      contents: read
    steps:
      - name: Checkout repository
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1  # v7
        with:
          persist-credentials: false
      - name: Install mise tools
        # cobo is pinned in mise.toml (pipx backend, Renovate-tracked) and run
        # via `mise exec`, mirroring how ghalint/all-contributors are invoked.
        uses: jdx/mise-action@e6a8b3978addb5a52f2b4cd9d91eafa7f0ab959d  # v4.2.0
      - name: Refresh cobo sources
        run: mise exec -- cobo update
      - name: Check for gitignore drift
        run: mise exec -- cobo check
```
